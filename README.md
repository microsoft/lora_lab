# Fine Tune Phi Silica with LoRA adapters

This repo contains a pretrained adapter, the AI Toolkit Visual Studio Code extension to enable you to train an adapter, datasets so you can fine tune your own adapter, and a sample app to test your trained adapter. You can follow the instructions detailed in the docs folder.
